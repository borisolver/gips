# GIPS — Grok Improvement Proposals

Static GitHub Pages site. Edit `proposals.json`, `template.html`, `styles.css`, or `site.js`, then run `python3 build.py` to regenerate `index.html` and `gips.json`.

`logo.png` is the supplied GIPS logo. `evidence/` contains the original public report images, unaltered; `evidence/sources.json` records their source URLs and hashes. Reports with no relevant screenshot remain linked; unrelated social previews are omitted. All site assets use relative paths.
