GIPS

Grok Improvement Proposals

A cast does not complain about a fracture. It sets it. GIPS turns real, documented Grok failures into specific, testable repairs.

Prepared for SpaceX / xAI decision-makers · Prototype v0 · November 2026 · Independent proposal; not affiliated with or endorsed by xAI.

Two-minute summary

  1. Source: all 16 proposals below cite public user reports from the CleanApp corpus (~1.29M AI-analyzed reports). Each report ID links to the original record.
  2. Pattern: Grok's model quality is rarely the complaint. The friction is at the seams: gates before value, handoffs without links, unverified claims about people and artifacts, billing after outages, developer predictability.
  3. Ask: each GIP is scoped so one engineer and one PM could ship or A/B test it in a sprint, with a named metric.
  4. Persistence: each card shows how long the problem has been publicly documented. Several have been open for over a year.
  5. Highest leverage first: GIP-01 (answer before upsell), GIP-02 (every handoff is a link), GIP-03 (ground people and roles).

GIP-01

Answer first, upsell second

411 days open
First reported 2025-09-19
Last checked 2026-11-04: no resolution recorded in CleanApp*
3 report(s)
Problem
New and free users hit a sign-up or paywall modal before getting a single answer, and paid-tier nudges read as pressure. The first impression of Grok becomes a wall rather than intelligence.
Evidence
  • 2026-10-15 rpt_8uuBMzU2Grlpuz7kcXZCcQ Grok web: 'tell me about CleanApp' immediately triggers an unskippable sign-up modal, no first-turn answer (Oct 15, 2026)
  • 2026-09-09 rpt_r2rBlr1tXIzkv7rMn3ofJw X places the in-thread Grok assistant behind Premium (Sep 9, 2026)
  • 2025-09-19 rpt_ZS9g3VadKr_ndpqo53mJVA User describes being 'gaslit and manipulated' into joining SuperGrok (Sep 19, 2025)
Proposed fix
Guarantee one complete, high-quality answer per anonymous session (rate-limited by device/IP), then show the upsell under the answer with the specific capability the user just missed (longer context, Deep mode, images). A/B test against the current hard gate.
Impact (estimate)
Directional estimate: conversion funnels typically lose most visitors at a pre-value gate; showing value first should lift sign-up conversion and reduce negative word-of-mouth. Measure as anonymous-to-signup rate over 2 weeks.
GIP-02

Every handoff must be a link

225 days open
First reported 2026-03-24
Last checked 2026-11-04: no resolution recorded in CleanApp*
3 report(s)
Problem
Grok tells users to 'continue in a 1:1' or sign in elsewhere without saying where; the X-to-Grok sign-on path and web login are reported broken. Users get stranded mid-task.
Evidence
  • 2026-10-15 rpt_4FxP2JghhF3UR0iHD-YIvQ Grok refuses in a group thread and asks for a 1:1 with no link or context (Oct 15, 2026)
  • 2026-10-15 rpt_MbuOXv_CKEh36TDEcptLqQ Sign-on flow from X to Grok still broken after latest updates (Oct 15, 2026)
  • 2026-03-24 rpt_Eb_y3T72i4m8XeeZBYZNJw Gmail sign-in on x.ai loads half the page and freezes (Mar 24, 2026)
Proposed fix
Policy plus lint rule: any response that redirects the user (to DM, to sign-in, to another surface) must include a deep link that carries the task context. Add an end-to-end synthetic check of the X → Grok auth path on every release.
Impact (estimate)
Estimate: removes a dead-end class of failures entirely; tracked as 'redirect without link' rate (target 0) and auth-completion rate.
GIP-03

Ground people and roles before asserting them

447 days open
First reported 2025-08-14
Last checked 2026-11-04: no resolution recorded in CleanApp*
2 report(s)
Problem
Grok states confident but false facts about who holds which role and what a web page says. For an assistant wired into X, misidentifying executives is a reputational and legal exposure.
Evidence
  • 2026-02-11 rpt_YpV5CL6aPvNhcyAjd_BtMg Grok identifies a user as 'X CEO' in a generated outreach plan (Feb 11, 2026)
  • 2025-08-14 rpt_LXL-Hj9wL2iFkR_TjjjQYA Grok misreads a site footer as claiming an xAI integration that does not exist (Aug 14, 2025)
Proposed fix
For claims about a named person's title or an organization's affiliation: require a retrieved source, cite it inline, and fall back to 'unverified' wording when none is found. Add these cases to a regression eval set.
Impact (estimate)
Estimate: narrow, high-severity hallucination class; measurable via a role-attribution eval (precision on title claims) before/after.
GIP-04

Verify the artifact before claiming it

453 days open
First reported 2025-08-08
Last checked 2026-11-04: no resolution recorded in CleanApp*
2 report(s)
Problem
Grok replies as though it produced an image that the user never receives, and renders text in images wrongly (a public 'every day until Grok gets it right' challenge).
Evidence
  • 2025-08-18 rpt_hn2nCgNHF3jjy2K_7XTZVg Grok on X describes a generated image; user replies 'I see no image' (Aug 18, 2025)
  • 2025-08-08 rpt_Z3noi2BOv3PAgYu8FMSV2Q Cybertruck render with 'TESLA' turned into 'TESLA MEFFERTRUCK' (Aug 8, 2025)
Proposed fix
Post-generation check: confirm the media attachment exists before the reply text references it; run OCR on generated images that contain requested text and regenerate on mismatch.
Impact (estimate)
Estimate: eliminates 'phantom image' replies; text-in-image accuracy measurable via OCR match rate on a fixed prompt set.
GIP-05

Long-session voice health monitor

444 days open
First reported 2025-08-17
Last checked 2026-11-04: no resolution recorded in CleanApp*
2 report(s)
Problem
Grok voice in Tesla degrades gradually over minutes until reset. As Grok voice moves into Starlink customer support, a slow degradation becomes a customer-facing quality issue.
Evidence
  • 2025-08-17 rpt_y0rjQjbGGcYutAzc9FMQdQ Grok voice in a Tesla degrades over minutes, needs reset (Aug 17, 2025)

Outage-aware billing and refunds

423 days open
First reported 2025-09-07
Last checked 2026-11-04: no resolution recorded in CleanApp*
3 report(s)
Problem
Paying users lose service (outages, app hangs, purchases not provisioned) and then face refund denials. Billing friction turns a technical incident into a trust incident.
Evidence
  • 2026-01-28 rpt_KuFFnM4Z-lb33TgxIzl5wA Paid on Jan 24, service unusable Jan 26–27, refund denied (Jan 28, 2026)
  • 2025-09-07 rpt_Sh7rTt5tFdlv-IEwNTcKuQ SuperGrok bought via Apple App Store but service not received (Sep 7, 2025)
  • 2026-02-06 rpt_1AJXP4VhLA65_mSbvxLruQ Grok app freezes at 98% loading every time (Feb 6, 2026)
Proposed fix
Automatic pro-rated credits for documented outages; a self-serve 'I paid but have no access' entitlement check that reconciles App Store receipts; a status page linked from error screens.
Impact (estimate)
Estimate: lowers refund-dispute and chargeback volume; measure support tickets tagged billing/entitlement per 1k subscribers.

GIP-08

Close the loop: Grok as its own issue-intake

344 days open
First reported 2025-11-25
Last checked 2026-11-04: no resolution recorded in CleanApp*
2 report(s)
Problem
Users already report Grok bugs to @grok in public, and Grok replies, even offering escalation, but there is no visible tracking. Reports evaporate.
Evidence
  • 2025-11-25 rpt_AwANPJbi7JmqRYK875mehA @grok offers escalation/review via a HackerOne ID in reply to a report (Nov 25, 2025)
  • 2025-11-25 rpt_JnLFMp4k3npMFy96OG4Djg Grok suggests a 'Grok bug' and offers escalation assistance (Nov 25, 2025)
Proposed fix
When a user reports a Grok defect to Grok, create a structured ticket (repro, surface, version), return a tracking link, and post back when fixed. Cluster duplicate reports so engineering sees frequency, not anecdotes. This is the CleanApp method, built in.
Impact (estimate)
Estimate: converts public complaints into a ranked backlog; measure report-to-fix time and duplicate clustering rate.

* "Open" means: first public report date to the date this page was compiled, with no fix or resolution recorded in the CleanApp record. It is not a confirmation from xAI that the issue is unresolved. Impact lines are estimates and stated reasoning, not measured results. Report counts are not affected-user counts; reports reflect what users chose to write down.

Method

  1. 1 · CollectReports from app, web, X, Bluesky, Reddit and GitHub enter one corpus.
  2. 2 · StructureAI extracts product, surface, severity and a neutral summary; original wording is kept.
  3. 3 · ClusterRelated reports are grouped so a pattern, not an anecdote, drives each proposal.
  4. 4 · PrescribeEach cluster becomes a GIP: problem, evidence, a shippable fix, and a metric to prove it.
